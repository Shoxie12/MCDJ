# MCDJ

This mod allow you to add as many records as you like.
<br>Just open playlist menu (Main menu -> Mods -> MCDJ -> Config) and drag&drop your .mp3 files and restart Minecraft!

<br>MCDJ now uses FFmpeg to work with MP3. So you need to <a href="https://www.ffmpeg.org/download.html">download</a> and install it firts

More information about installing, configuring, and working with this mod can be found in <a href="https://github.com/Shoxie12/MCDJ/wiki">MCDJ Wiki</a>
